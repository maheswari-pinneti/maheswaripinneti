# Maheswari Pinnetti Portfolio

## Overview
A premium professional developer website, engineering portfolio, project showcase, and technical blog built for Maheswari Pinnetti. It demonstrates expertise in React, TypeScript, Node.js, SQLite, and 3D web experiences.

## Features
- **Profile & Identity**: Professional story and experience timelines.
- **Projects & Work**: Deep case studies, particularly for WFA-SQLite.
- **Engineering Lab**: Visualizations of architecture, APIs, and databases.
- **Test Lab**: Live display of test results (Unit, E2E, Accessibility).
- **Playground**: Interactive 3D experiments and mini-games.
- **Articles**: Technical writing platform.

## Architecture
- **Frontend**: React, TypeScript, Vite, React Router
- **State**: Redux Toolkit, TanStack Query
- **Styling**: Vanilla CSS with custom properties (Dark Luxury Theme)
- **3D**: Three.js, React Three Fiber
- **Backend**: Node.js, Express, better-sqlite3 (Monolithic structure)
- **Testing**: Vitest (Unit), Playwright (E2E), React Testing Library

## Tech Stack
- React, TypeScript, Vite
- Node.js, Express
- SQLite
- Three.js
- Docker, CI/CD

## Development Environment
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```

## Design System
- Dark theme with `#0a0a0a` background and `#10b981` (Emerald) accents.
- Responsive, accessible, and fast.
